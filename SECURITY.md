# Security Policy

This is an independent, community-maintained project (Apache-2.0, provided as-is).

## Reporting a vulnerability

Please report security issues **privately** via GitHub Security Advisories:

- Go to the repository's **Security → Advisories → Report a vulnerability**
  ([Privately report a vulnerability](https://github.com/SammZhu/openshift-capi-alicloud/security/advisories/new)).

This keeps the report confidential until a fix is available. Please do **not** open
a public issue for security reports. The maintainer ([OWNERS](OWNERS)) will respond
on a best-effort basis.

## Supported versions

Only the latest `v0.1.x` release receives fixes.
